# Аудит работоспособности Doppel (2026-10-25)

Проверено: все исходники (`cli.mjs`, `config.mjs`, `up.mjs`, `mirror.mjs`,
`shots.mjs`, `styles.mjs`, `mirror-app/*`), незакоммиченный diff, логи
`~/Library/Logs/Doppel`, живые процессы на :3141/:3142, worktrees hw-bench.
`node --check` всех файлов проходит. Node 25.8.1, Electron 45.0.0 (совпадает с lock).

Пункты помечены: **[факт]** - подтверждено запуском или логами,
**[код]** - видно по коду, не воспроизводилось.

## Высокий приоритет: потеря рабочей среды, зависание, сироты

### 1. `up` убивает порты до проверки ref'ов - `up.mjs:48-51`
**[код]** Сначала `lsof | xargs kill`, потом `prepare()` делает `git rev-parse`.
Опечатка в ref (`doppel up origin/mian .`) гасит оба работающих сервера, после
чего `up` падает. Также убивается любой слушатель порта, даже чужой dev-сервер.
Fix: вызвать `rev-parse` для обеих сторон до kill; перед kill проверять, что
процесс запущен из `doppel-<name>-*` (lsof `-F` + cwd) или хотя бы печатать, кого убиваем.

### 2. Гонка: порт ещё занят, когда стартует новый сервер - `up.mjs:50`, `up.mjs:106`
**[код]** SIGTERM отправлен, ожидания освобождения порта нет. При `build: null`
или быстрой сборке новый `start` получает EADDRINUSE и падает. `waitUp` при этом
может получить ответ от ещё живого старого сервера и `up` напечатает "ready",
хотя новая версия не запущена (в терминале промелькнёт "B on :3142 stopped (code 1)").
Fix: после kill опрашивать `lsof -t` до пустого вывода (до 10 с), затем SIGKILL.

### 3. Серверы-сироты при любом исключении после spawn - `up.mjs:104-122`
**[код]** `waitUp` бросает "did not come up" -> top-level await завершает процесс,
`stop()` не вызывается, detached-группы серверов остаются жить. Аналогично для
любого uncaught. Дополнительно `fetch` в `waitUp` без таймаута: сервер, который
принимает соединение и молчит, подвешивает `up` навсегда.
Fix: `try { await waitUp } catch { stop() }`; `AbortSignal.timeout(3000)` в fetch;
`process.on("exit")` как последняя линия обороны.

### 4. `git worktree remove` падает на чужой папке - `up.mjs:63`
**[код]** `name` по умолчанию = basename корня. Два разных проекта с папкой `app`
делят `$TMPDIR/doppel-app-a`. Если папка есть, но не зарегистрирована как
worktree этого репозитория (другой проект, остатки после `prune`, другой $TMPDIR),
git бросает непонятную ошибку и `up` не стартует.
Fix: в имя добавлять короткий хеш `c.root`; при ошибке remove делать `fs.rmSync`.

### 5. Общий `node_modules` у двух параллельных сборок - `up.mjs:66`, `up.mjs:98`
**[код]** Symlink на `node_modules` пользователя. Тулчейны, которые пишут кэш в
`node_modules/.cache` (webpack, babel-loader, eslint, некоторые SWC/Vite плагины),
получают две конкурентные записи плюс сборку самого пользователя. Итог: флаки сборки,
ложные различия в `shots`. **[факт]** У hw-bench `.cache` сейчас нет, для Next 15
риск не актуален. Для других проектов стоит задать переменные кэша в `env` или
собирать стороны последовательно опцией.

### 6. `mirror` может повиснуть на focus-эмуляции B - `mirror-app/main.js:210-213`
**[код]** `debugger.sendCommand("Emulation.setFocusEmulationEnabled")` ждёт ответа.
По комментарию в коде команда не отвечает, пока у B нет страницы. Если сервер B
не поднялся на старте, `await` не завершается: финальный лог не печатается,
`:focus-visible` в B не появится и после восстановления, а в `--selftest` будет
таймаут 180 с (код 2). Fix: вызывать на первом `did-finish-load` B и оборачивать
в `Promise.race` с таймаутом.

### 7. Headless Chrome остаётся при ошибке - `shots.mjs:44,118`, `styles.mjs:48,263`
**[код]** `browser.close()` стоит только на успешном пути. Исключение вне try
(ошибка записи файла, Ctrl+C) оставляет процессы Chrome. Fix: `try/finally` и
обработчики SIGINT/SIGTERM с `browser.close()`.

## Средний приоритет

### 8. Память в `shots` - `shots.mjs:38,61,74-88,95`
**[код]** Буфер PNG = `w * total * 4`. При 4k и `MAX_H` 40000 это ~600 МБ на
картинку; на один job A, B, diff и две padded копии - до 3 ГБ; три воркера
параллельно. Длинная страница на 4k даст OOM или своп.
Fix: один воркер для размеров шире 2560, `MAX_H` 20000, не создавать padded копии
когда высоты равны (сейчас `pad` возвращает оригинал - ок, но diff всё равно полный).

### 9. Путь с пробелом ломает `cli` и `mirror` - `cli.mjs:27`, `mirror.mjs:31`
**[код]** `new URL(import.meta.url).pathname` не декодирует `%20`. Если Doppel
клонирован в папку с пробелом или кириллицей, `cli` не найдёт `up.mjs`, а `mirror.mjs`
решит, что Electron не установлен, запустит `npm install` и упадёт.
Fix: `fileURLToPath(import.meta.url)` (в `main.js` уже так).

### 10. `--ports` без валидации - `config.mjs:72`
**[факт]** `--ports 3141` даёт `ports[1] = undefined` -> `http://localhost:undefined`;
`--ports 3141,abc` даёт NaN. Fix: требовать ровно два целых 1..65535.

### 11. Двойная загрузка B после навигации - `mirror-app/sync.js:88-95`
**[код]** Через 700 мс после навигации A сравниваются пути. Если B навигируется
по зеркальному клику медленнее (холодный Next после `--only b`), поверх летит
`loadURL` -> прерванная загрузка, мигание, потеря состояния страницы.
Fix: пропускать, если `target.isLoading()`; или сверять после `did-navigate` B.

### 12. `theme` до проверки `THEMES`, глобальный глотатель ошибок - `main.js:189-193`, `watch.js:23`
**[код]** `new URL(a.webContents.getURL())` стоит до `if (!THEMES) return` и бросает
при пустом URL; на `chrome-error://` загрузит мусор. Исключение тихо глотается
`uncaughtException` в `watch.js`, приложение живёт в неопределённом состоянии.
В `--selftest` uncaught лучше считать провалом прогона.

### 13. Retry грузит устаревший URL - `main.js:111-119`
**[код]** После `did-fail-load` через 1.5 с грузится упавший `url`. Если
пользователь успел уйти на другой адрес, пане вернётся на старый.
Fix: перед `loadURL` сравнивать с текущим `getURL()` A.

### 14. Два контекстных меню при правом клике - `main.js:153-163`, `record.cjs:40`
**[код]** Правый клик в A зеркалится в B (`b: 2`), `context-menu` срабатывает в
обоих -> два popup "Inspect". Fix: не зеркалить `button === 2` или не вешать
меню на B при зеркальном событии.

### 15. Самолечение `npm install` в `mirror.mjs:34-38`
**[код]** Без сети падает со stack trace; молча меняет `node_modules` Doppel.
Fix: ясное сообщение с командой для ручного запуска.

### 16. `codesign` с `stdio: ignore` - `mirror.mjs:70`
**[код]** При ошибке подписи виден только стек без причины. Показать stderr.

### 17. Копирование рабочей копии - `up.mjs:66-74`
**[код]** `copyFileSync` падает на битом symlink, сокете, fifo среди untracked.
`symlinkSync` для `link` даёт EEXIST, если файл трекается в git (например `.env`
и в `link`, и в репо), и ENOENT, если родительской папки нет в worktree.

### 18. `sh()` без `error`-обработчика, незакрытые fd - `up.mjs:53-58,105`
**[код]** Если shell не запустился, промис висит. fd лог-файлов не закрываются.

### 19. Папка отчёта с точностью до минуты, UTC - `shots.mjs:40-41`
**[код]** Два запуска за минуту смешиваются в одной папке.

### 20. Нет предпроверки доступности A/B в `shots` и `styles`
**[код]** Каждый job падает отдельно с `ERR_CONNECTION_REFUSED`, отчёт из одних
ошибок. Один `fetch` до запуска даст ясное "A :3141 не отвечает, запусти doppel up".

### 21. Информативность провала selftest - `selftest.js:13-16`
**[факт]** Лог 10:15: `unhandled-rejection "Script failed to execute"` и выход по
таймауту через 2.5 минуты. Незакоммиченный try/catch (`selftest.js:107-112`)
убирает таймаут, но `center()` всё ещё бросает внутри страницы, и сообщение не
называет селектор. Fix: `querySelector` -> null -> `throw new Error("no element: " + sel)`.

## Низкий приоритет и гигиена

- `package.json`: нет `engines` (нужен Node >= 18: fetch, top-level await, `Array.at`).
- Нет автотестов кроме `mirror --selftest`; хотя бы `node --check` всех файлов в скрипте.
- Electron `^45.0.0`: мажор в API `console-message` (сменился в 32) и обход крэша
  `disableDeviceEmulation` в `viewport.js:13-15` привязаны к версии. Лучше точный pin.
- `shots`: имена файлов из route не экранируют `:` `%` `#` и пробелы.
- `main.js:54`: окно всегда на primary display.
- `main.js:197-199` (`go`): полный URL превращается в `A//http://...`.
- `record.cjs`: нет `mouseleave` - B держит hover после ухода мыши из A; IME/composition не зеркалятся.
- `docs/how-it-works.md:70-79` устарел: говорит, что `render-process-gone` не обрабатывается, хотя `watch.js` уже есть.
- `mirror.mjs:92-99`: `appendFileSync` на каждый chunk stderr и на каждый `console-error` в `watch.js:34-36`;
  страница, спамящая `console.error`, тормозит main-процесс и раздувает лог. Нужен троттлинг.
